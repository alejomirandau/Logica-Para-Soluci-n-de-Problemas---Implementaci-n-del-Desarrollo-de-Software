Sistema de Gestión de Restaurante

Lógica Para Solución de Problemas  
Universidad Católica Luis Amigó  
Alejandro Miranda Usuga

Descripción:
Este sistema automatiza el ciclo de servicio de un restaurante, desde la reserva inicial del cliente en su hogar hasta la facturación final. Incluye la asignación de mesas por parte de los meseros, la gestión de pedidos en tiempo real para la cocina y el procesamiento de pagos.
